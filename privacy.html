Founder Cuts

Privacy policy

Effective date: 17 October 2026

This policy explains how the "Founder Cuts Uploader" application ("the app"), operated by Founder Cuts, handles data. The app is a private tool used only by Founder Cuts to manage its own YouTube channel @foundercutsco. It is not offered to the public.

Data the app accesses

Through the YouTube API Services, with the account owner's explicit consent via Google OAuth, the app:

  • uploads videos created by Founder Cuts to the Founder Cuts YouTube channel (scope youtube.upload);
  • reads public information and statistics (such as view counts) of videos on that channel (scope youtube.readonly).

The app does not access the data of any other YouTube user, and it does not collect personal data from viewers.

How data is used and stored

  • Upload results and video statistics are stored in a private database on a server controlled by Founder Cuts. They are used only to schedule uploads and to measure the performance of Founder Cuts' own clips.
  • OAuth tokens are stored on that private server in a file readable only by the app, and are never shared.
  • Data is not sold, rented or shared with third parties, and it is not used for advertising.
  • The app's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

The app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. For how Google handles data, see the Google Privacy Policy.

Retention and deletion

Statistics are kept for as long as needed to measure clip performance. Access can be revoked at any time at myaccount.google.com/permissions. After revocation, the stored tokens are deleted, and on request any stored data is deleted within 30 days.
